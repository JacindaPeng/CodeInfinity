# 数据结构设计文档

> 对应《小学期课程实践项目说明书》提交物（3）项目文档 · 数据结构设计  
> ORM：SQLAlchemy 2.x（`backend/app/models/__init__.py`）  
> 建表与种子：`backend/scripts/init_db.py`  
> 增量迁移：`backend/scripts/run_migrations.py`

关系数据存 **SQLite**（`data/course.db`）；向量与检索元数据存 **Chroma**（`data/chroma`）；上传文件存文件系统（`data/uploads`）。

---

## 一、实体关系总览

```
Course 1──* Chapter 1──* KnowledgePoint
                └──* Material 1──* VideoSegment
User *──* TeachingClass（class_enrollments / class_teachers）
Agent *──* TeachingClass（agent_classes）
Agent 1──* Material / ExamConfig / QuestionBank（可选作用域）
User 1──* Exam 1──* ExamQuestion
         └── 0..1 ExamReport
ExamImportJob 1──* ExamImportFile
              1──* QuestionCandidate →（发布）QuestionBank
KnowledgeSource 1──* KnowledgeArticle 1──* KnowledgePush → User
TeachingClass 1──* ClassChatMessage / ClassChatDm / ClassChatRead
```

## 二、用户与班级

### users

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| username | VARCHAR(64) UNIQUE | 登录名 |
| password_hash | VARCHAR(255) | bcrypt |
| role | VARCHAR(16) | `student` / `teacher` / `admin` |
| display_name | VARCHAR(64) | 昵称 |
| phone | VARCHAR(20) UNIQUE NULL | 新注册绑定；存量可空 |
| class_id | FK teaching_classes NULL | 兼容旧字段；多课选课以 enrollments 为准 |
| feedback_credit | INTEGER | 判卷反馈信誉分 |
| created_at | DATETIME | |

### teaching_classes

| 字段 | 说明 |
|------|------|
| id, name | 班级主键与名称 |
| invite_code | VARCHAR(8) UNIQUE，学生加入用 |
| course_id | 关联课程（可空） |
| created_by | 创建教师 user_id |
| created_at | |

### class_enrollments

学生选课记录。约束：`UNIQUE(user_id, course_id)` → **每门课最多加入一个班**。

| 字段 | 说明 |
|------|------|
| user_id, class_id, course_id | 学生、班级、课程 |
| joined_at | 加入时间 |

### class_teachers

协作教师：`(class_id, user_id)` 复合主键。

## 三、课程体系与资料

| 字段 | 说明 |

## 五、考核与题库

### exam_configs

按 `(chapter_id, class_id, agent_id)` 唯一。

| 字段 | 说明 |
|------|------|
| config_json | 如 `{"选择题":2,"判断题":2,"简答题":2,"knowledge_points":["指针",...]}` |
| max_attempts | 次数上限；`0` = 不限 |

### question_bank

| 字段 | 说明 |
|------|------|
| chapter_id / class_id / agent_id | 作用域 |
| kp_id | 关联知识点 |
| type | 选择题 / 判断题 / 简答题 / 填空题 等 |
| stem, options_json, answer, analysis | 题干、选项、答案、解析 |
| source_import_job_id 等 | 考卷导入溯源 |
| content_hash | 去重 |
| extra_chapter_ids_json / extra_kp_names_json | 综合题额外标签 |

对应平台要求的「习题—知识点标注」。

### exam_import_jobs / exam_import_files / question_candidates

往年卷导入流水线：

| 表 | 要点 |
|----|------|
| exam_import_jobs | status、progress、settings_json、stats_json |
| exam_import_files | role=`paper`/`answer`，parse_status |
| question_candidates | 候选题；status=`pending`/`approved`/`rejected`；confidence |

发布后写入 `question_bank`。

### exams / exam_questions / exam_reports

| 表 | 要点 |
|----|------|
| exams | user + chapter 一次考核；status=`ongoing`/`submitted` |
| exam_questions | source=`bank`/`llm`；得分、AI 评语、知识点名 |
| exam_reports | dimensions_json、summary、suggestions、total_score、weak_points |

### exam_question_followups

报告页单题追问：question / answer / recommendations_json。

### exam_grading_feedbacks

学生对某题判卷 `agree` / `disagree`；含 `reward_delta`、教师确认。

### exam_interventions

判卷争议：trigger=`auto`/`manual`；status=`pending`/`resolved`/`dismissed`；师生留言与裁定分数。

### chapter_progress

用户章节状态：未完成 / 已完成 / 待学习；`last_exam_id`。

## 九、向量库（Chroma）

| 项 | 说明 |
|----|------|
| 路径 | `CHROMA_PATH`（默认 `../data/chroma`） |
| Embedding | 见下表 |
| 切分 | `langchain_text_splitters.RecursiveCharacterTextSplitter` |
| 集合名 | ONNX → `course_knowledge`；Hash → `course_knowledge_hash` |

| `CHROMA_EMBEDDING_MODE` | 说明 |
|-------------------------|------|
| `hash` / `offline` / `local` | 本地哈希向量（Docker 默认） |
| `onnx` | Chroma 默认 ONNX MiniLM |
| `auto` | 有本地 ONNX 缓存则用 ONNX，否则 hash（不触发下载） |

### Chunk metadata（常见字段）

| 字段 | 说明 |
|------|------|
| material_id | 资料 ID |
| chapter_id / course_id | 章节 / 课程 |
| type / title | 资源类型与标题 |
| agent_id / class_id | 作用域过滤 |
| video_start_sec / video_end_sec | 视频片段时间（若有） |

检索时按当前智能体/班级/章节过滤，避免跨作用域串扰。

## 十、文件系统与路径解析

| 目录 | 用途 |
|------|------|
| `data/course.db` | SQLite |
| `data/chroma/` | Chroma 持久化 |
| `data/uploads/` | 课件、视频、考卷等上传文件 |
| `data/chroma_onnx_cache/` | Docker 下 ONNX 模型缓存挂载（可选） |

`materials.file_path` 不单独建「路径表」；运行时由 `services/storage_paths.py` 解析：

1. 优先按库内路径直接打开  
2. 不存在则回退 `UPLOAD_DIR + 文件名`（兼容 Windows 路径写入后在 Linux 容器读取）

## 十一、初始化与种子数据

`python -m scripts.init_db`（Docker 启动时自动执行）：

- 创建全部表结构  
- 写入默认管理员 / 教师 / 学生账号  
- 种子课程《C 语言程序设计》及预设智能体、基础章节等  

后续结构变更走 `scripts/run_migrations.py`，避免覆盖已有业务数据。
