## 一、账号与认证

| 功能 | 入口 | 说明 |
|------|------|------|
| 落地页 | `/welcome` | 产品介绍、角色路径与核心能力展示，进入登录 |
| 注册 | `/register` | 仅学生/教师；须手机号 + 短信验证码；用户名≥3、密码≥6；不可注册 admin |
| 密码登录 | `/login` | 用户名 + 密码 → JWT |
| 手机登录 | `/login`（手机 Tab） | 手机号 + 验证码 → JWT |
| 发送验证码 | `POST /api/auth/sms/send` | scene=`register` \| `login`；开发模式返回 `dev_hint`，码默认 `123456` |

存量账号可无手机号，仍可用密码登录。新注册账号绑定唯一手机号，保证账号与手机一一对应。

## 二、按角色功能

### 2.1 学生

| 功能 | 路由 | 说明 |
|------|------|------|
| 首页 | `/home` | 功能入口卡片 |
| 大模型对话 | `/chat` | 通用 SSE 对话（附件/语音可选）；与课程 RAG 问答相互独立 |
| 我的智能体 | `/agents` | 可见课程智能体列表（系统预设 + 班级绑定） |
| 智能体介绍 / 主页 | `/agents/:id`、`/agents/:id/home` | 介绍与课程空间入口 |
| 课程问答 | `/course-qa` | RAG SSE 流式回答 + 右侧学习资源推荐；可限定章节 |
| 章节学习路线 | `/chapters` | 章节状态（未完成/已完成/待学习）；开始考核 / 查看报告 |
| 考核作答 | `/exams/:id` | 逐题作答并提交 |
| 考核报告 | `/exams/:id/report` | 总分、维度雷达图、薄弱知识点、复习建议；错题追问、判卷反馈、申请教师介入 |
| 我的班级 | `/my-class` | 邀请码加入/退出；同一课程仅能加入一个班级 |
| 课程群聊 | `/class-chat` | 群消息、话题讨论、与教师私信 |
| 知识推送 | `/knowledge-push` | 基于薄弱点的今日推荐；已读/忽略；可手动触发一轮 |

### 2.2 教师

除学生侧问答/考核/群聊外，额外具备：

| 功能 | 路由 | 说明 |
|------|------|------|
| 班级管理 | `/teacher/classes` | 建班、自动邀请码、刷新邀请码、学生/协作教师、绑定智能体 |
| 资料管理 | `/teacher/materials` | 上传 PPT/PDF/Word/视频；教材拆章；课件批量；重建索引 |
| 考核配置 | `/teacher/exam-config` | 按章节（及班级/智能体作用域）配置题型数量、知识点、次数上限 |
| 题库管理 | `/teacher/question-bank` | 题库 CRUD；往年卷 PDF 导入 → 拆题审核 → 发布入库 |
| 考核记录 | `/teacher/exam-records` | 查看学生试卷与报告、班级进度 |
| 判卷介入 | `/teacher/exam-interventions` | 处理学生争议 / 自动介入单；裁定分数与留言 |
| 调用日志 | `/logs` | 本人相关 LLM/智能体调用记录 |
| 教师智能体 | `/agents` 内管理 | 创建、共享、采纳他人共享智能体；绑定班级；状态筹备中/已上线 |

教师创建智能体时可填写名称、简介、绑定课程与状态。「筹备中」不对普通学生开放；绑定班级后学生方可进入课程空间。共享后其他教师可「采纳」得到独立副本，互不影响资料与题库。

## 三、核心业务流程

### 3.1 教学资源入库（对应平台「教学资源库」）

1. 教师在资料管理上传 PPT / PDF / Word / 视频（可指定章节、班级、智能体）
2. 系统解析文本；视频经 Whisper 转写并按时间切段
3. 文本切分为 Chunk，写入 Metadata（资源类型、章节、课程、知识点、agent/class 等）
4. 向量写入 Chroma，形成课程知识库
5. 索引异常时可用「重建索引 / 仅视频重索引 / 教材重拆」修复

教材上传支持自动拆章生成章节路线；识别不准时可手工自定义目录。

### 3.2 课程问答（RAG）

1. 选择当前课程智能体与可选章节
2. 提问 → 在作用域内混合检索相关 chunk
3. LLM 基于上下文 **SSE 流式** 输出
4. 同步给出 PPT / PDF / 视频等推荐；视频含 `video_start_sec` 时可跳转对应片段
5. 可回顾历史问答并再次追问

接口：`POST /api/agents/course/ask`（SSE）；独立推荐 `POST /api/recommend`。

与「大模型对话」的区别：课程问答严格基于教师上传资料的知识库；通用对话为开放式 LLM 会话。

### 3.3 章节考核（重点功能）

**教师侧**

1. 按章节配置：知识点、选择题/判断题/简答题数量、及格线、次数上限
2. 维护题库（手工录入或往年卷导入拆题审核）
3. 在章节路线查看班级进度；在考核记录查看报告；处理判卷介入

**学生侧**

1. 章节学习路线选择「开始考核」
2. 系统按配置从题库抽题，不足部分由大模型补足，生成动态试卷
3. 作答提交后自动批改：
   - 选择/判断：标准答案比对
   - 简答：LLM 按维度打分与评语
4. 报告页展示：总分、多维雷达图、薄弱知识点、复习建议
5. 可对单题追问；对判卷结果 agree/disagree；争议可申请教师介入

形成「学生考核 → 报告反馈 → 教师介入」的教学闭环。

### 3.4 班级与智能体

1. 教师创建班级并生成邀请码，绑定一个或多个智能体
2. 学生凭邀请码按课程加入（同课仅一班，防止串班）
3. 资料、知识点、考核配置按 `agent_id` / `class_id` 隔离
4. 协作教师可加入班级，共享管理权限

### 3.5 课程群聊

- 班级内群消息
- 话题发起与回复（可关联知识点）
- 学生与教师私信
- 已读游标与未读数

### 3.6 知识推送

1. 依据考核报告中的薄弱知识点
2. 从管理员维护的白名单 RSS（及可选搜索）匹配文章
3. 定时（`KNOWLEDGE_PUSH_HOUR/MINUTE`）或学生手动 `POST /knowledge-push/run` 推送
4. 学生可标记已读/忽略；管理员查看统计与记录

### 3.7 考卷导入

教师上传试卷（及可选答案）PDF → 解析拆题 → 候选题审核（改题型/章节/知识点，通过或拒绝）→ 发布写入题库。

## 五、接口协议约定

| 项 | 约定 |
|----|------|
| 业务 API 前缀 | `/api` |
| 鉴权 | `Authorization: Bearer <token>`（注册/登录/发短信除外） |
| 流式输出 | `text/event-stream`（课程问答、通用对话） |
| 健康检查 | `GET /health`（无 `/api` 前缀） |
| 交互文档 | 运行后端后访问 `/docs`（Swagger） |

细节见 [API接口文档.md](./API接口文档.md)。

## 六、演示路径建议（与逐字稿对齐）

1. 欢迎页 → 注册/短信登录能力说明  
2. 教师：班级管理 → 大模型对话 → 调用日志  
3. 教师：创建/共享/采纳课程智能体

5. 教师：题库/考卷导入 → 考核配置 → 章节路线/记录/介入  
6. 学生：加入班级 → 章节考核 → 报告/追问/介入  
7. 学生：课程群聊 → 知识推送  
8. 管理员：用户/智能体/LLM/全站记录/推送运维/AI 反馈
