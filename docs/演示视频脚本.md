# 演示视频脚本（约 12–15 分钟）

> 按顺序录制；账号默认 `admin/admin123`、`teacher/teacher123`、`student/student123`。  
> 开发短信模式验证码：`123456`。

## 0:00 — 0:40 开场

- 产品名：**CodeInfinity** 课程智能体平台  
- 定位：多课程 RAG 问答 + 章节考核 + 班级教学  
- 技术栈一句话：Vue3 + FastAPI + SQLite + Chroma + DeepSeek；短信可选阿里云 PNVS  
- 展示落地页 `/welcome`

## 0:40 — 1:40 启动方式（二选一）

**本地（推荐演示）：**

- 后端：`backend\install.bat`（已装可跳过）→ 配置 `.env` → `python -m scripts.init_db` → `dev.bat`  
- 前端：`npm run dev` → `http://localhost:5173`  
- 打开 `http://127.0.0.1:8000/docs` 一闪而过即可  

**或 Docker：** `docker-compose up -d --build` → `http://localhost`

## 1:40 — 2:30 登录与角色

- 密码登录 teacher；扫一眼侧栏：班级、资料、考核、智能体  
- 切出登录页，演示「手机验证码」Tab：发送验证码（开发模式可用 123456），说明新注册必须绑手机  
- 切回 teacher

## 2:30 — 4:00 班级与智能体

- 「班级管理」：展示邀请码；说明学生按课程入班  
- 「我的智能体」：进入某课程智能体主页；简述可共享/采纳（有数据则点开共享入口）

## 4:00 — 5:30 知识库（教师）

- 「资料管理」：上传一份 PDF 课件到某章，展示索引成功  
- （可选）上传短视频，说明 Whisper 转写与时间戳（耗时可剪辑加速）  
- 展示「重建索引」入口即可，不必等全量跑完

## 5:30 — 7:00 课程问答 + 推荐（学生）

- 登录 student →「课程问答」  
- 问一个课内问题（如指针与数组区别 / 循环结构）  
- 展示 SSE 流式回答 + 推荐卡片  
- 若有视频推荐，点击时间跳转

## 7:00 — 8:30 考核配置与题库（教师）

- 「考核配置」：选一章，设选择/判断/简答数量与知识点  
- 「题库管理」：新增 1–2 道题；口头说明「考卷导入」：上传 PDF → 拆题审核 → 发布（有现成任务则打开审核页）

## 8:30 — 10:30 学生考核全流程

- student →「章节学习路线」→ 开始考核  
- 作答数题 → 提交  
- 「学习报告」：雷达图、总分、薄弱点、复习建议  
- 对一题点「追问」或「判卷反馈」（有则演示）

## 10:30 — 11:30 班级群聊与知识推送

- 「课程群聊」：发一条群消息；可开话题或私信入口  
- 「知识推送」：今日列表；说明按薄弱知识点日推；可点「刷新/生成」类按钮（若有）

## 11:30 — 12:30 教师阅卷与介入

- teacher →「考核记录」打开学生报告  
- 「判卷介入」：若有 pending 单则处理；否则说明学生反馈争议后出现在此

## 12:30 — 13:30 管理端（admin）

- admin 登录 →「用户管理」「智能体管理」  
- 「大模型配置」：展示提供商与默认项  
- 「知识推送记录 / AI 判卷反馈」入口扫过  

## 13:30 — 14:00 收尾

- 回顾三大核心：问答 · 推荐 · 考核，以及班级/智能体/推送扩展  
- 文档位置：`README.md`、`docs/`  
- 结束画面：落地页或首页
