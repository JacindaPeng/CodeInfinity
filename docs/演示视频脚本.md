# 演示视频脚本（≥10 分钟）

> 总时长约 12 分钟，按下列顺序演示。

## 0:00 — 0:30 开场与项目介绍
- 项目名称：《C语言程序设计》课程智能体
- 三大核心功能：课程问答 / 资源推荐 / 章节考核
- 技术栈：Vue3 + FastAPI + SQLite + Chroma + LangChain + DeepSeek

## 0:30 — 1:30 部署演示
- 终端执行 `cp .env.example .env`，填入 DeepSeek API Key
- `docker-compose up -d --build`
- 浏览器访问 `http://localhost`
- 展示 Swagger 文档 `http://localhost:8000/docs`

## 1:30 — 2:30 用户登录与首页
- 使用 `admin/admin123` 登录
- 展示首页功能卡片
- 介绍左侧菜单结构（学生/教师视图差异）

## 2:30 — 4:00 大模型配置（教师）
- 进入「大模型配置」
- 新增 DeepSeek 配置，填入 API Key，设为默认
- 进入「大模型对话」页，提问「C 语言中指针是什么？」演示 SSE 流式回答

## 4:00 — 6:00 知识库构建（教师）
- 进入「资料管理」
- 上传一个 PDF（如「第五章 指针.pdf」），选择章节，提交
- 展示索引成功（索引片段数增加）
- 上传一个视频，展示自动转字幕并索引
- 点击「重建索引」演示全量重建

## 6:00 — 7:30 课程问答 + 资源推荐（学生）
- 切换 `student/student123` 登录
- 进入「课程问答」
- 提问：「什么是 AVL 树？如何平衡调整？」
- 演示流式回答 + 右侧「建议学习」资源卡片
- 点击「跳转视频 2:00」按钮，演示视频精准定位到知识点时间点

## 7:30 — 9:00 章节考核配置（教师）
- 切换 teacher 账号
- 进入「考核配置」，选择第六章
- 配置：选择题 2 / 判断题 2 / 简答题 2，知识点选「AVL树」「平衡调整」
- 进入「题库管理」，新增 2 道选择题，演示 CRUD

## 9:00 — 11:00 章节考核全流程（学生）
- 切换 student 账号
- 进入「章节学习路线」，展示时间线（未完成/已完成/待学习）
- 点击「开始第二章考核」（用题库充足的章节演示更稳定）
- 逐题作答，演示进度条与暂存
- 提交考核

## 11:00 — 12:00 学习评价报告
- 自动跳转到报告页
- 展示四维度雷达图（知识掌握 / 基础概念 / 综合分析 / 建议复习）
- 展示总体评价与复习建议
- 展示题目回顾（错题、正确答案、AI 评语）
- 展示「自适应学习推荐」——基于薄弱维度自动检索的复习资源
- 返回章节路线图，展示状态变为「√ 已完成」

## 12:00 — 12:30 结尾
- 总结功能完整性、创新点（视频时间精准定位、自适应学习推荐）
- 致谢

## 演示注意事项

1. 演示前确保 `docker-compose up` 正常运行、数据库已初始化
2. 提前在数据库中准备好至少 1 个章节的题库（避免依赖 LLM 实时生成不稳定）
3. 课程问答演示前先上传 1-2 份真实 PDF，确保检索有结果
4. 视频跳转演示用短视频（<1 分钟）避免转写等待
5. 若 LLM 响应慢，演示时说明「流式特性」
