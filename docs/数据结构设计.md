# 数据结构设计文档

通过 SQLAlchemy 2.x ORM 定义（`backend/app/models/__init__.py`），建表与种子见 `backend/scripts/init_db.py`，增量迁移见 `scripts/run_migrations.py`。

## 一、用户与班级

### users
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| username | VARCHAR(64) UNIQUE | |
| password_hash | VARCHAR(255) | bcrypt |
| role | VARCHAR(16) | student / teacher / admin |
| display_name | VARCHAR(64) | |
| phone | VARCHAR(20) UNIQUE NULL | 新注册绑定 |
| class_id | FK teaching_classes NULL | 兼容旧字段；多课选课以 enrollments 为准 |
| feedback_credit | INTEGER | 判卷反馈信誉 |
| created_at | DATETIME | |

### teaching_classes
| 字段 | 说明 |
|------|------|
| id, name, invite_code UNIQUE | 班级与邀请码 |
| course_id | 关联课程（可空） |
| created_by | 创建教师 |
| created_at | |

### class_enrollments
学生选课：`(user_id, course_id)` 唯一 → 每门课最多一个班。

### class_teachers
`(class_id, user_id)` 复合主键，协作教师。

## 二、课程体系

### courses / chapters / knowledge_points
- chapters：`course_id`，可选 `agent_id`，`order_idx`  
- knowledge_points：`chapter_id`，可选 `class_id`、`agent_id`  

### materials / video_segments
- materials：`type`=ppt/pdf/video/word；可选 `class_id`、`agent_id`；`file_path`、`meta_json`  
- video_segments：字幕分段 `start_sec` / `end_sec` / `subtitle_text`  

## 三、智能体

### agents
| 字段 | 说明 |
|------|------|
| name, intro, endpoint, slug, status | 展示与入口；status=active/planned |
| course_id | 所属课程 |
| owner_id | 教师拥有者；空可为系统预设 |
| source_agent_id | 采纳来源 |
| is_shared, shared_at | 是否共享 |
| source_snapshot_at | 采纳快照时间 |
| UNIQUE(owner_id, name) | |

### agent_classes
智能体与班级绑定：`agent_id` + `class_id` 唯一。

## 四、考核与题库

### exam_configs
按 `(chapter_id, class_id, agent_id)` 唯一；`config_json` 含题型数量与知识点列表；`max_attempts`（0=不限）。

### question_bank
题型、题干、选项、答案、解析；可选 `kp_id`、`class_id`、`agent_id`；综合题可有 `extra_chapter_ids_json` / `extra_kp_names_json`。

### exam_import_jobs / exam_import_files / question_candidates
往年卷导入流水线：任务状态、文件角色（paper/answer）、候选题审核状态（pending/approved/rejected）与置信度等。

### exams / exam_questions / exam_reports
- exams：用户某章一次考核，status=ongoing/submitted  
- exam_questions：source=bank/llm；得分与 AI 评语  
- exam_reports：dimensions_json、summary、suggestions、total_score、weak_points  

### exam_question_followups
报告页单题追问记录。

### exam_grading_feedbacks
学生对某题判卷 agree/disagree；可有教师确认与信誉变动。

### exam_interventions
判卷争议：trigger=auto/manual；status=pending/resolved/dismissed；含师生留言与裁定分数。

### chapter_progress
用户章节状态：未完成 / 已完成 / 待学习；`last_exam_id`。

## 五、LLM 与日志

### llm_configs
provider、api_key、base_url、model、is_default。

### call_logs
endpoint、摘要、tokens、model、全文答案、附件 JSON、延迟等。

## 六、知识推送

### knowledge_sources
白名单 RSS：`rss_url`、tags、enabled、resource_type。

### knowledge_articles
拉取文章：url 唯一、title、summary、keywords_json、published_at。

### knowledge_pushes
`(user_id, article_id)` 唯一；reason、kp_names_json、status=unread/read/dismissed。

## 七、班级聊天与短信

### class_chat_messages
msg_type=text/topic/topic_reply；可选 parent_id、knowledge_point_id。

### class_chat_dms
班级内师生私信。

### class_chat_reads
已读游标：channel 形如 `group` / `topic:{id}` / `dm:{peer_id}`。

### sms_codes
phone、scene、code_hash（开发模式存哈希；PNVS 模式哨兵值）、expires_at、attempts、consumed。生产校验走阿里云 CheckSmsVerifyCode。

## 八、向量库（Chroma）

- 路径：`CHROMA_PATH`（默认 `../data/chroma`）  
- Embedding：Chroma 默认 ONNX MiniLM（无需额外 sentence-transformers）  
- 文档切分：`langchain_text_splitters.RecursiveCharacterTextSplitter`  
- Chunk metadata 常见字段：`material_id`、`chapter_id`、`type`、`title`、视频起止秒、`agent_id` / `class_id`（若有）  

检索时按当前智能体/班级/章节过滤，避免跨作用域串扰。

## 九、实体关系（简图）

```
Course 1──* Chapter 1──* KnowledgePoint
                └──* Material 1──* VideoSegment
User *──* TeachingClass (enrollments / class_teachers)
Agent *──* TeachingClass (agent_classes)
Agent 1──* Material / ExamConfig / QuestionBank（可选作用域）
User 1──* Exam 1──* ExamQuestion
         └── 0..1 ExamReport
ExamImportJob 1──* QuestionCandidate →（发布）QuestionBank
KnowledgeSource 1──* KnowledgeArticle 1──* KnowledgePush → User
```
