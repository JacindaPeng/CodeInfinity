# 功能说明文档

## 一、基础功能（统一要求）

### 1.1 用户管理
| 功能 | 入口 | 说明 |
|------|------|------|
| 用户注册 | `/register` | 学生/教师角色可选，用户名≥3、密码≥6 |
| 用户登录 | `/login` | JWT 鉴权，返回 access_token |
| JWT 身份认证 | 全局 | axios 拦截器自动带 Bearer Token，401 自动跳登录 |
| 用户信息管理 | `/users/me` | 获取当前用户 |

### 1.2 系统管理
| 功能 | 路由 | 说明 |
|------|------|------|
| 系统首页 | `/home` | 功能卡片展示 |
| 大模型配置 | `/llm-config` | 教师/管理员 CRUD，支持 DeepSeek/OpenAI/Qwen，可设默认 |
| 智能体管理 | `/agents` | 智能体列表与介绍 |
| 智能体介绍 | `/agents/:id` | 详情页 |
| 调用历史日志 | `/logs` | 教师/管理员查看所有 LLM/智能体调用记录 |

### 1.3 智能体相关
| 功能 | 入口 | 说明 |
|------|------|------|
| 大模型对话 | `/chat` | 通用对话 SSE 流式 |
| 智能体介绍 | `/agents/:id` | 智能体能力说明 |
| 智能体调用 | `/course-qa` | 课程问答 RAG SSE 流式 + 资源推荐 |

## 二、课程智能体核心功能

### 2.1 功能一：课程问答（RAG）

- **学生提问**：在 `/course-qa` 输入问题（如「什么是 AVL 树？」），可选限定章节
- **检索**：Chroma 向量检索 top-5 课程资料切片
- **回答**：LLM 基于检索上下文流式生成答案
- **历史**：支持多轮对话，自动携带最近 6 条历史

### 2.2 功能二：学习资源推荐

- **触发**：每次课程问答后自动生成
- **依据**：当前问题 + 当前章节 + 检索命中的 chunk 元数据
- **推荐类型**：PPT / PDF / Word / 视频
- **视频精准定位**：检索命中视频字幕 chunk 时，返回 `video_start_sec`，前端可跳转到对应时间点播放
- **独立接口**：`POST /api/recommend` 可单独调用

### 2.3 功能三：章节考核（重点）

#### 教师端
- **考核配置** `/teacher/exam-config`：为每章配置选择题/判断题/简答题数量与考核知识点
- **题库管理** `/teacher/question-bank`：题库 CRUD，支持三种题型
- **资料管理** `/teacher/materials`：上传 PPT/PDF/Word/视频，自动解析索引

#### 学生端
- **章节学习路线** `/chapters`：时间线展示各章状态（未完成/已完成/待学习），可开始考核或查看历史报告
- **考核答题** `/exams/:id`：逐题作答，进度条，支持上一题/下一题/暂存
- **试卷生成策略**：
  1. 题库按章节+题型随机抽题
  2. 不足数量由 LLM 基于章节知识点动态生成补足
- **自动评分**：
  - 选择题/判断题：直接对比答案
  - 简答题：LLM 按「参考答案 + 维度」打分（0-100）+ 评语
- **学习评价报告** `/exams/:id/report`：
  - 四维度雷达图：知识掌握情况 / 基础概念掌握 / 综合分析能力 / 建议复习知识点
  - 总体评价 + 复习建议
  - 题目回顾（含错题、正确答案、AI 评语）
- **自适应学习推荐（创新）**：报告页基于薄弱维度自动检索推荐复习资源

## 三、接口协议

- 管理接口：HTTP REST（GET/POST/PUT/DELETE）
- 大模型/智能体调用：SSE 流式（`text/event-stream`）
- 所有接口统一前缀 `/api`
