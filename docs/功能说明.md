# 功能说明文档

## 一、账号与认证

| 功能 | 入口 | 说明 |
|------|------|------|
| 落地页 | `/welcome` | 产品介绍与进入登录 |
| 注册 | `/register` | 学生/教师；须手机号 + 短信验证码；用户名≥3、密码≥6；不可注册 admin |
| 密码登录 | `/login` | 用户名 + 密码 → JWT |
| 手机登录 | `/login`（手机 Tab） | 手机号 + 验证码 → JWT |
| 发送验证码 | API `/api/auth/sms/send` | scene=`register` \| `login`；开发模式返回 `dev_hint`，码默认 `123456` |
| 当前用户 | `/api/users/me` | Bearer Token；axios 401 跳转欢迎页 |

存量账号可无手机号，仍可用密码登录。新注册账号绑定唯一手机号。

## 三、核心业务流程

### 3.1 课程问答（RAG）

1. 选择当前课程智能体与可选章节  
2. 提问 → Chroma 检索相关 chunk  
3. LLM 基于上下文 SSE 输出  
4. 同步或随后给出 PPT/PDF/视频等推荐；视频含 `video_start_sec` 时可跳转  

接口：`POST /api/agents/course/ask`（SSE），独立推荐 `POST /api/recommend`。

### 3.2 章节考核

**教师**：配置题型数量与知识点 → 维护题库（可导入考卷）→ 查看记录与介入。  

**学生**：章节页开始考核 → 题库抽题不足由 LLM 补足 → 提交自动批改：

- 选择/判断：标准答案比对  
- 简答：LLM 维度打分与评语  

报告：总分、维度雷达、薄弱点、复习建议；可对单题追问、对判卷反馈；争议可申请教师介入。

### 3.3 班级与智能体

1. 教师创建班级并生成邀请码，绑定一个或多个智能体  
2. 学生按课程加入班级（同课仅一班）  
3. 资料、知识点、考核配置按 `agent_id` / `class_id` 隔离，避免串班串课  

教师可共享智能体，其他教师「采纳」得到独立副本继续改资料与题库。

### 3.4 知识推送

- 定时（`KNOWLEDGE_PUSH_HOUR/MINUTE`）或学生手动 `POST /knowledge-push/run`  
- 依据考核薄弱知识点，从白名单 RSS（及可选搜索）匹配文章写入推送  
- 管理员维护 `knowledge_sources`、查看推送记录  

### 3.5 考卷导入

教师上传试卷（及可选答案）PDF → 解析拆题 → 候选题审核（改题型/章节/知识点）→ 发布写入题库。

| 用户管理 | — | — | ✓ |

## 五、接口协议

- 业务 API 前缀：`/api`  
- 鉴权：`Authorization: Bearer <token>`（注册/登录/发短信除外）  
- 流式：`text/event-stream`（课程问答、通用对话等）  
- 健康检查：`GET /health`（无 `/api` 前缀）  

细节见 [API接口文档.md](./API接口文档.md) 与运行中 Swagger。
